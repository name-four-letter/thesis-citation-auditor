# 수정 필요도 점수

`수정 필요도`는 독자가 잘못된 결론을 얻을 위험과 수정의 긴급도를 나타내는 0–100점 우선순위다. 인용 필요도와 별도로 산정한다.

## 산정

아래 신호를 합산하고 100점에서 상한을 둔다. 같은 문제를 중복 가산하지 않는다.

- **+45**: 인용 원문이 핵심 주장과 직접 모순되거나, 인용-문헌 대응 자체가 잘못됨.
- **+35**: 수치, 단위, 표본/소자, 측정 조건, 시간 범위 또는 비교 기준이 원문과 다르게 서술됨.
- **+25**: 검증 가능한 핵심 주장에 인용이 없거나, 인용된 자료가 다른 대상을 다룸.
- **+20**: 인용은 관련되지만 핵심 절·수치·한계·인과관계 중 일부만 뒷받침함.
- **+15**: 상관관계, 서로 다른 연구의 비교, 일반화 또는 인과관계가 근거 범위를 넘음.
- **+10**: 용어, 단위, 인용 위치, 표기 또는 문체 불일치가 의미 해석을 방해함.

원문을 확보하지 못한 경우에는 확인 가능한 위험 신호만으로 임시 점수를 매기고 `판단 자료 부족`을 명시한다. 이 경우 권장 조치는 문장 삭제나 단정적 수정이 아니라 관련 원문 또는 합법적 공개본 확인이다.

## 해석과 조치

| 점수 | 분류 | 기본 조치 |
|---:|---|---|
| 0–19 | 수정 불필요 또는 미미 | 유지하거나 선택적 문체 수정 |
| 20–39 | 소폭 수정 권장 | 표현·용어·인용 위치 정리 |
| 40–64 | 수정 권장 | 문장 범위·근거·인용을 보완 |
| 65–84 | 우선 수정 | 제출 전 원문 대조 후 수정 |
| 85–100 | 즉시 수정 | 핵심 오류를 바로 고치고 관련 표·그림·인용까지 재검증 |

보고서에는 항상 원본 문장을 권장 수정안 바로 위에 두고, 점수만으로 자동 수정하지 않는다.
